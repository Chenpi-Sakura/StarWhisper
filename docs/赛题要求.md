# 2026华为云OPC创意大赛
> 页面链接：https://developer.huaweicloud.com/competition/information/1300000299/circumstance

## 赛题详情
### 【赛题形式】开放型赛题
本次大赛采用开放型赛题，不限创意内容与技术方向，鼓励所有符合社会正向价值的作品参与。无论你做的是一款效率工具、一个 AI 应用、一个内容创作助手，还是一个有趣的实验性产品，都可以参赛。

### 【要求】使用华为云码道开发
作品开发过程**必须使用华为云码道**（AI Coding 工具，点击下载）作为 AI 编程工具，并提交码道使用痕迹证明，例如：
- IDE 插件日志（码道插件使用记录）
- 华为云控制台操作记录
- AI 交互 prompt 截图
- 代码生成与修改记录

请务必**保留开发过程记录**（可以作成视频、PPT等证明材料）。

### 【作品提交规范】
#### 初赛作品规范：
1. 整体介绍PPT或PDF；
2. 参赛作品（需提供安装包或演示URL，或者提供安装工具包）；
3. 视频（视频内容需包括作品功能演示，上载作品包可以是视频文件，也可以是视频的有效URL，建议时长3min以内）；
4. 码道使用证明（截图、视频）；
5. zip压缩包命名规范：作品名称+选手名称+版本号+联系方式（示例详见本页底）。

#### 决赛作品规范：
1. 整体介绍PPT或PDF；
2. 参赛作品（需提供安装包或演示URL，或者提供安装工具包）；
3. 视频（视频内容需包括功能演示，上载作品包可以是视频文件，也可以是视频的有效URL，建议时长3min以内）；
4. zip压缩包命名规范：作品名称+选手名称+版本号+联系方式。

### 【建议】搭配华为云服务
以下华为云服务可与码道搭配使用，让你的作品更完整：
- AgentArts —— 智能体应用开发
- OfficeAce —— 办公 AI
- AI Shell —— 自然语言一键部署上云
- 更多云服务

## 初赛评选规则
线上评审 9.7 ~ 9.8（根据提交的素材评审，提供模板）

**评分口径（100分制）**
- 核心价值 80 分
  - 创新易用 20分 / 商业前景 20分 / 技术架构 20分 / 功能完备 20分
- 码道深度应用 20 分
  - 码道使用占比
  - 开发过程展示或使用痕迹证明（IDE 日志 / 控制台 / prompt 截图）

## 决赛评选规则
路演评审 9.17（现场展示产品、答辩）

**评分口径（100分制）**
- 核心价值 80 分
  - 创新易用 20分 / 商业前景 20分 / 技术架构 20分 / 功能完备 20分
- 现场路演表现 20 分
  - 路演 8 / 答辩 8 / 时间控制 4

### 【评分细则】
| 考核内容 | 评审内容 | 作品评审细项 |
|---|---|---|
| 创新易用（20分） | 创意或作品在商业模式、管理运营、流程优化、应用场景等方面具有一定突破和创新。 | 1.本项目是否具有区别于市场同类产品的差异化创新？<br>2.本项目是否开创了新的产品或服务类别？ |
| 商业前景（20分） | 要求参赛作品有一定的社会效益或商业价值 | 1.产品当前的状态？是否有明确的市场或受众？主要功能是否与受众需求相匹配<br>2.在市场推广、资源获取、合规性、计划等方面，是否具有可行性？是否有合理的投资回报预期，是否能创造较好的社会价值或市场收益？ |
| 技术架构（20分） | 以 AI 原生为核心，采用 OPC 轻量化架构，支持一人独立开发、部署、运维；技术选型合理，架构稳定、安全、可扩展，匹配各产业发展。 | 技术融合度：是否有效结合了主流AI技术与工具的优势，技术选型是否与OPC 应用场景高度匹配。<br>OPC架构适配性：是否采用了轻量化、低成本的架构设计，支持一人独立开发、部署与运维，具备良好的弹性与落地可行性。<br>多产品生态协同：是否充分利用其他云服务或产品或技术包括但不限于云原生、开源组件、鸿蒙原生智能、端边云协同及跨终端能力。在同等技术条件下，具备优秀用户体验的产品将获得显著加分。<br>架构质量：技术架构是否合理，是否具备良好的稳定性、安全性与可扩展性，能支撑AI应用的长期高效运行。 |
| 功能完备（20分） | 创意或产品综合考虑了待解决问题的各个方面，且对各种可能出现的问题都有完备的功能实现，核心功能可用，逻辑设计流程顺畅，操作体验流畅，且不存在明显功能欠缺。 | 1.核心功能是否逻辑顺畅、可运行、不存在明显欠缺？<br>2.界面设计、用户交互设计等，是否具有专业级的表现能力？是否能够让用户轻松流畅地操作，且有良好体验？ |
| 码道深度使用（20分） | 产品开发阶段码道的使用频率、token的消耗量 | 提交码道控制台的页面截图数据 |
| 现场路演表现（20分） | 路演表现/答辩表现/时间控制 | 路演表现(产品功能4分，讲解介绍4分），答辩表现8分（知识储备4分，解决问题能力4分），时间控制4分（超时1分钟扣1分） |
