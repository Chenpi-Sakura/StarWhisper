## M4 — 收尾上线（9.3 – 9.6）

### 1. 观星条件（原 brief §6 "M3 观星条件" → 推迟到 M4）

| 模块 | 内容 | 来源 |
|---|---|---|
| **IndexView（首页重做）** | M2 占位"M3 接入"；M4 真正实现 | spec §0.4 |
| **浏览器定位** | navigator.geolocation + 国内主要城市兜底 | spec §0.4 |
| **Open-Meteo 聚合** | `cloud_cover` `precipitation_probability` `wind` `temperature` hourly | brief §5 + spec 文件结构 §6（`weather.py` 已留位） |
| **月相计算** | `astral` 库算新月/上弦/满月/下弦 + 月照量折算 | spec §0.4 |
| **Bortle 光污染查表** | `server/data/bortle_cities.json`（国内主要城市经纬度→Bortle 等级 I~IX） | spec 文件结构 §6 |
| **指数算法** | `Score = 云量 40% + 降水 20% + 风/温度 10% + 月相 20% + 光污染 10%` | brief §5 |
| **一票否决** | 云量>80% 或降水>50% → 指数≤40 强制"差" | spec §18 |
| **时段曲线** | 未来 24h 逐小时评分曲线（可切换 7 天） | brief §6 |
| **输出分档** | 优/良/一般/差 四档（前端 UI 直接用） | brief §6 |

**关键文件**

- `server/services/weather.py` — Open-Meteo 客户端（spec 文件结构 §6 已留位）
- `server/services/index.py` — 观星指数聚合（spec 文件结构 §6 已留位）
- `server/data/bortle_cities.json` — 国内主要城市→Bortle 等级映射
- `server/routers/index.py` — `GET /api/weather` + `GET /api/index?lat=&lon=`
- `web/src/api/stargaze.ts` — 前端 API（spec 文件结构 §6 已留位）
- `web/src/views/IndexView.vue` — spec 已标记"M2 占位，M3 接入" → 实际 M4 接入
- `web/src/views/ScanView.vue` 跨页跳转："看看今晚能不能看"按钮跳 IndexView（带用户当前坐标）

**外部依赖**

| API/库 | 用途 | 备注 |
|---|---|---|
| **Open-Meteo** | 云量/降水/风速/温度 | 免费、免 key、`api.open-meteo.com/v1/forecast` |
| **astral** | 月相/月升月落 | Python 库（pip install astral） |
| **Bortle** | 光污染等级 | 内置 JSON 查表 |

**兜底**

若 9.1 前观星指数页未完工，按 brief §6 红线降级为极简版（仅 Open-Meteo 云量 + 一档"今晚能不能看"判断），先保主卖点（M2 已完成）。
