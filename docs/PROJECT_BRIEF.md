# 项目简报 · 星语天象（StarWhisper）

> 2026 华为云 OPC 创意大赛 · 开放型赛题 | 文档版本：v0.1 | 更新日期：2026-08-20

---

## 1. 项目概述

**一句话定位**：让用户拍下的星空"开口说话"——拍照识星座、星座动起来、AI 讲神话。

**目标受众**：天文爱好者、摄影入门者、对星空好奇的大众。

**核心价值主张**：
- 现有的"天文通"解决「今晚能不能看」；本产品进一步解决「我拍到了什么、它有什么故事」。
- 用「识别 → 可视化 → 叙事」三步闭环，把冰冷的星表数据变成有温度的观星体验。

---

## 2. 核心功能

| 模块 | 功能 | 优先级 |
|---|---|---|
| 星点识别 | 上传/拍摄星空照片 → 后端中转 Astrometry.net 识别 → 返回画面内星座与恒星 | P0 主卖点 |
| 星座动起来 | 2D Canvas 绘制星座连线动画（星点闪烁、连线描出、缓旋转、入场动效） | P0 主卖点 |
| AI 星座故事 | 选中星座后，调用 LLM 以神话/科普双视角生成故事，支持重讲/换风格 | P0 主卖点 |
| 观星条件 | 云量 / 降水 / 温度 / 风 / 月相 / 光污染 → 综合观星指数 + 未来 24h 时段曲线 | P1（用户确认完整版） |
| 首页引导 | 定位（浏览器定位 + 城市搜索兜底）、功能区导航 | P1 |

**用户旅程**：`进入首页 → 查看今晚观星指数 → 上传/拍摄星空照片 → 识别星座 → 星座动起来 → 选择星座听 AI 讲故事 → 分享`

## 3. 技术栈与架构

### 开发与部署环境
- **开发机**：Windows + conda（Python 3.11）+ pnpm（Node ≥ 20）
- **服务器**：Linux（自有服务器），conda 管理 Python 环境，前端构建产物由后端托管或 Nginx 反代

### 技术选型
| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + Vite + TypeScript + pnpm | 单页应用，深空科技风（黑紫底、发光星点） |
| 后端 | Python 3.11 + FastAPI + uvicorn | conda 环境；REST API；图片内存处理不落盘 |
| 星点识别 | Astrometry.net 公共 API（nova.astrometry.net） | 后端中转避免跨域，异步轮询任务结果 |
| 星座数据 | 内置星座连线数据 + 恒星目录（HYG / Stellarium 数据子集） | 根据识别结果中心坐标反查可见星座 |
| 天文计算 | skyfield / astral / 自写月相计算 | 月相、日月升降等观星条件因素 |
| 天气 | Open-Meteo API（免费、无 Key） | 云量 / 降水概率 / 温度 / 风速（未来 24h+） |
| 光污染 | 按经纬度查询公开光污染数据 / 手动等级输入 | 参与观星指数加权 |
| AI 讲故事 | 通用 OpenAI 兼容 Chat API（封装 provider 接口） | 预留华为云盘古（ModelArts Studio）切换位 |
| 部署 | 自有 Linux 服务器，systemd 托管后端 | 公网 URL 供评审体验 |

## 4. 系统架构

```
┌──────────────┐     HTTPS      ┌──────────────────────────────┐
│  浏览器 (Vue3) │ ────────────▶ │  FastAPI 后端 (Linux, conda)   │
└──────────────┘               └──────────────────────────────┘
                                         │   ▲
                   上传/异步轮询识别        │   │
                                         ▼   │
                                 ┌───────────────────┐
                                 │ Astrometry.net API │
                                 └───────────────────┘
     后端依赖外部服务：Open-Meteo（天气）、AI Chat API（故事）、内置星表（星座）
```

- **OPC 轻量化**：单机部署，一人可独立开发/部署/运维；无重依赖，弹性扩展靠提高实例配置即可。
- **安全**：照片仅内存处理不落盘；后端对上传尺寸与类型做限制；AI Key 仅存服务端环境变量。

## 5. 观星指数算法（草案）

```
Score = 云量 40% + 降水 20% + 风/温度 10% + 月相 20% + 光污染 10%
```
- 云量取自 Open-Meteo hourly `cloud_cover`；降水取 `precipitation_probability`。
- 月相：新月/上弦/满月按月照量折算（满月减分，银河观测最忌满月）。
- 光污染：按 Bortle 等级（I~IX）映射系数。
- 输出：`优/良/一般/差` 四档 + 未来 24h 逐小时曲线（可切换为未来 7 天）。
